## 🌟 Overview

A modern, interactive personal portfolio website for **Anubhav Agarwal**, engineered to showcase expertise across Search Engine Optimization (SEO), Generative Engine Optimization (GEO), Performance Marketing, E-commerce Optimization (Shopify & Amazon Seller Central), Content Strategy, Graphic Design, and Website Management.

The site is built with a dark editorial technology aesthetic, featuring:
- **Kanit Typography**: Oversized bold headlines (`MARKETING MEETS INTELLIGENCE.`) with multi-stop linear metallic gradients.
- **Interactive 3D Hero Visual**: Floating metallic chrome sphere with rotating orbital rings, particle satellites, real-time cursor tilt physics, and live AI search query status capsules.
- **Dual-Direction Expertise Marquee**: Continuous, seamless looping horizontal rows showcasing 12 core marketing and technical domains.
- **White-Canvas Services Transition**: Crisp high-contrast section with oversized 01–05 numbering and expandable strategy & deliverables drawers.
- **Selected Work Case Studies**: Sticky stacking cards with in-depth modals covering Business Challenge, Strategic Objective, Approach, Deliverables, Verified Outcomes, and Tools Used for:
  1. **GEO SEO Lab** (AI Search Visibility & GEO)
  2. **Sri Ganpati Collection** (Fashion Retail Growth & Campaigns)
  3. **Chloia** (Amazon & Shopify Listing Optimization)
- **Career Journey Timeline**: Reverse-chronological history across 6 verified positions plus an expandable leadership & campus experience drawer (MAIT DigiQuest'26, CU Graphic Design, Alumni Cell).
- **Verified Skills & Tool Ecosystem**: Categorized marketing capabilities with proficiency level indicators (no arbitrary percentages) and verified platforms (GA4, GSC, SEMrush, Ahrefs, Meta Ads, Shopify, Amazon Seller Central, WordPress, Canva).
- **Creative Portfolio Gallery**: Filterable visual showcase with full-screen lightbox asset inspector.
- **Verified Credentials & Education**: BBA in Digital Marketing (Chandigarh University), Class 12 (Ajmani International School), and verified LinkedIn Learning credentials.
- **Interactive Contact & Inquiry Form**: 1-click email copy with instant feedback, direct LinkedIn connection, verified printable resume modal, and realistic project inquiry dispatch with confetti celebration.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8 + `@tailwindcss/vite`
- **Styling**: Tailwind CSS v4 with custom design tokens
- **Animations & Interactions**: Framer Motion
- **Icons**: Lucide React + custom SVG brand icons
- **Micro-Interactions**: Canvas Confetti
- **Typography**: Google Fonts (`Kanit` and `Plus Jakarta Sans`)
- **SEO & Structured Data**: OpenGraph, Twitter Cards, Canonical links, JSON-LD (`Person` & `WebSite` schemas), `robots.txt`, and `sitemap.xml`.

## 🚀 Getting Started

### Prerequisites

Ensure [Node.js](https://nodejs.org/) (LTS v20+ or v24+) is installed.

### 1. Installation

```bash
npm install
```

### 2. Development Server

Start the local Vite development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build

Build the optimized, minified production assets with clean code splitting:

```bash
npm run build
```

The output files will be created in the `dist/` directory.

### 4. Preview Production Build

Preview the production build locally:

```bash
npm run preview
```
